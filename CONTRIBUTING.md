# Contributing

Thanks for your interest in improving FileConv.

## Before you start

- Open an issue for bugs, feature requests, or new converter ideas.
- Check whether the behavior already exists before starting a larger change.
- Keep changes small and easy to review.

## Development guidelines

- Follow the existing project structure.
- Add or update tests whenever you change behavior.
- Make sure new converters are imported so they are registered at startup.
- Keep code and comments clear and consistent.

## Suggested workflow

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Run tests and basic CLI checks.
5. Open a pull request with a short summary of the change.

## Documentation changes

If your change affects CLI behavior, supported formats, or installation steps, update the README and CHANGELOG at the same time.
