# Contributing to grubber

Thanks for wanting to contribute! A few guidelines.

## Getting started
1. Fork the repo.
2. Create feature branch:
   git checkout -b feature/brief-description

3. Run tests:
   pytest

## Code style
- Black: `black .`
- isort: `isort .`

## Commit messages
Prefer Conventional Commits:
- feat:, fix:, docs:, chore:, etc.

## Pull requests
- Rebase on main, add tests, explain changes.
